# Feature matrix — 0.9.5 developer preview

This matrix describes the checked-in implementation, not a stable-release promise. “Local/mock” means exercised against automated fixtures or the browser demo; it does not imply a live service acceptance test.

| Capability                                   | Atelier Bridge + Cards                                                                         | Home Assistant Core Mealie + Cards                                                                   | Standalone Web                                                                        |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Recipe catalog and ingredient search         | Yes; bridge paging                                                                             | Read-only; requests up to 500 matches in one response and locally pages loaded matches in sets of 24 | Yes; server proxy paging                                                              |
| Recipe detail and cooking steps              | Yes                                                                                            | Read-only via Core response actions                                                                  | Yes                                                                                   |
| Recipe/step photos                           | Authenticated signed image routes                                                              | Hidden unless an authenticated trusted proxy is configured                                           | Server-side image proxy                                                               |
| Meal planning and shopping                   | Read/write subject to server settings and Mealie token                                         | Not provided by the Atelier Core fallback                                                            | Read/write subject to server settings and Mealie token                                |
| Cookbooks and kitchen metadata               | Yes                                                                                            | Not exposed by this fallback                                                                         | Yes                                                                                   |
| Recipe create/import/edit                    | Available with HA admin checks; schema limits apply                                            | Not available                                                                                        | Available to authenticated app user; schema limits apply                              |
| Discover wizard, pantry helpers, family view | Yes; household state stored by provider                                                        | Local recipe browsing only                                                                           | Yes; stored by companion server                                                       |

## Known limits

- Core provider calls the documented `mealie.get_recipes` and `mealie.get_recipe` response actions. The card asks for up to 500 matches in a single response, then locally pages through those loaded matches in sets of 24. It does not fetch additional service pages; larger catalogs can be incomplete. The actual configured household catalog and Core action contract must be smoke-tested in the target HA version.
- Core mode is deliberately read-only and does not invent recipe image URLs or expose Mealie credentials to the browser.
- Recipe ingredient text replacement remains experimental and opt-in; full schema-aware ingredient editing and image upload are not implemented.
- Recipe picker in weekly planning is limited to currently loaded recipes. Offline queued writes are not implemented. Core-provider timers are browser-local; server-managed alarms require the Bridge or standalone provider and a working configured notification channel.
- Standalone Web uses a shared household account; it does not provide per-person logins.
- Real HA/Mealie acceptance, public HACS publication, physical iPhone Duo, and physical printer checks remain open. See [release readiness](RELEASE_READINESS_0.9.5.md).
