Mealie Atelier Cards is planned as a standalone-first recipe experience for browsing, planning and cooking from your Mealie library. Home Assistant cards are an optional way to bring the same kitchen tools into a dashboard.

## Planned experience

- Find recipes by name or ingredients with a fast, helpful search.
- Choose what to cook from the recipes you already have.
- Follow clear cooking steps with practical timers and ingredient scaling.
- Use the experience on a phone, tablet or kitchen display, with installable PWA support in mind.
- Use German and English, with a structure that can grow to more languages.
- Add Home Assistant cards without making Home Assistant a requirement for the core experience.

These describe the intended direction, not features currently available in this repository.

## Project status

This repository is currently an empty project starter. It contains no runnable application, live demo, installation package, or verified compatibility information yet. Do not use it as an installation guide. We will publish setup steps, supported versions, screenshots and test results alongside the first working preview.
